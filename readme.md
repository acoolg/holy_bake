```hbk

```

**Output:**

```mcfunction
execute hell
```

## How to use

1. Put your `.txt` file in a folder called `holy_text` (if it doesn't exist, create it yourself).
2. Run:

```powershell
npm run make
```

3. The result will be in a folder called `holy_function`.
